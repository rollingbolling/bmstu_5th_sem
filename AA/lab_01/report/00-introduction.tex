\chapter*{\hfill{\centering  ВВЕДЕНИЕ}\hfill}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Целью данной лабораторной работы является исследование алгоритмов поиска расстояний Левенштейна и Дамерау~---~Левенштейна.

Для достижения поставленной цели необходимо выполнить следующие задачи:
\begin{enumerate}
    \item описать алгоритмы поиска расстояний Левенштейна и Дамерау~---~Левенштейна для нахождения редакционного расстояния между строками;
    \item реализовать данные алгоритмы;
    \item выполнить сравнительный анализ алгоритмов по затрачиваемым ресурсам (времени, памяти);
    \item описать и обосновать полученные результаты в отчете.
\end{enumerate}
